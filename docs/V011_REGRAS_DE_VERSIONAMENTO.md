# Registro de versionamento da v0.11

**Data:** 07/11/2026.

A versão v0.11 usa a matriz 0.3.3, motor Python 0.1.2, índice IPR-PET/1.0.0 e adaptador Google Gemini. Nesta branch GitHub, os arquivos `V011_*.md` são **registros de documentação**. Não implicam que a branch contenha todos os módulos do aplicativo v0.11.

O código integral, testes e docs foram organizados em pacote ZIP da v0.11 e em commit Git local independente, com bundle próprio para publicação autorizada em uma branch de código. O GitHub deve receber esse bundle/código antes de se declarar a versão atual publicada no repositório. Sem merge automático em `main`.
